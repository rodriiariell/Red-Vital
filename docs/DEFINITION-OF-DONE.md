# Definition of Done

- Criterios de aceptación cumplidos.
- Cambios revisados.
- Pruebas correspondientes ejecutadas.
- Errores críticos resueltos.
- Seguridad y privacidad revisadas cuando aplique.
- Documentación actualizada.
- Sin código de aplicación en este repositorio de planificación hasta que el equipo lo incorpore explícitamente.
- Reglas clínicas validadas profesionalmente antes de implementarse.
